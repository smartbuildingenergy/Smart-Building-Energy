# Security Policy

## Supported Versions

| Component | Status |
|---|---|
| Live demo environment | Active — demo data only |
| Application source (private) | Active |

## Reporting a Vulnerability

If you discover a security vulnerability in the demo environment or in this repository, please report it responsibly.

**Contact:**

**ILHAN CEKIC, PhD**  
[LinkedIn — Ilhan Cekic](https://www.linkedin.com/in/ilhan-cekic-212b4a4a/)

Please include:

1. A description of the vulnerability
2. Steps to reproduce
3. Potential impact
4. Your suggested fix (if any)

**Please do not:**

- Publicly disclose the vulnerability before it has been addressed
- Attempt to access, modify, or exfiltrate data beyond what is needed to demonstrate the vulnerability
- Perform denial-of-service attacks against the demo environment

## Response

We aim to acknowledge security reports within 5 business days and provide an initial assessment within 10 business days.

## Scope

This policy covers:

- The live demo at `https://smart-building-energy-demo.netlify.app`
- The content of this public showcase repository

It does not cover:

- Third-party services (Netlify, GitHub) — report those directly to the respective providers
- The private application repository — contact directly

## Demo Environment Notes

The demo environment uses intentionally public credentials (`demo` / `A1234`). These are not a vulnerability. The demo environment contains only synthetic data and is completely isolated from any production systems.
