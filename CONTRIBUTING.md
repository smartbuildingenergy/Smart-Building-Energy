# Contributing

## About This Repository

This is a **public showcase repository** for the Smart Building Energy platform. It contains documentation, architecture descriptions, and product information — not application source code.

## What You Can Contribute

Contributions are welcome in the following areas:

### Documentation Improvements

- Corrections to factual errors
- Improved clarity or structure
- Translation improvements (the platform supports DE / EN / TR)
- Grammar and spelling fixes

### How to Contribute

1. Fork this repository
2. Create a branch (`git checkout -b docs/your-improvement`)
3. Make your changes
4. Submit a Pull Request with a clear description of what you changed and why

### What We Will Not Accept

- Application source code (this is a documentation-only repository)
- Marketing claims that go beyond what the platform currently does
- Fabricated screenshots or demo data presented as real
- Changes that claim savings, certifications, or capabilities not yet verified

## Accuracy Standards

All contributions must adhere to the platform's core principles:

- **Estimated ≠ Verified** — Do not claim savings without M&V evidence
- **Demo ≠ Production** — Do not present demo data as real operational data
- **Screening ≠ Prediction** — Do not present pilot building selection as a savings forecast
- **Diagnosis ≠ Causality** — Do not claim proven causality from anomaly detection
